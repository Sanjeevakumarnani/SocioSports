# SocioSports

A full-stack sports community platform for discovering, organizing, and participating in sports activities.

## Overview

SocioSports is designed around the social side of sports: users can discover activities, connect with other players, and manage sports-related interactions through a modern web application.

## Stack

- React / TypeScript
- Vite
- Tailwind CSS
- Node.js
- Prisma
- SQLite / relational persistence
- REST-style application services

## Engineering focus

- Component-driven frontend architecture
- Responsive UI
- Typed application code
- Database-backed application state
- Authentication and role-aware flows
- Reusable sports and community features

## Development

Clone the repository and install dependencies with the package manager used by the project.

Then run the development services according to the repository setup scripts and technical documentation.

See TECHNICAL_DOCS.md and the project configuration for the current application structure.

## Status

Active portfolio project. The SocioSports repository represents the primary full-stack implementation, while older versions are retained separately for development history.
