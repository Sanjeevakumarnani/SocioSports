# SocioSports Frontend PRD

## UI/UX Goals
1. **Responsive Design**: Must work on mobile and desktop.
2. **Interactive Elements**: Use of animations (Framer Motion/GSAP).
3. **Core Pages**:
   - Home: Overview of the platform.
   - Events: Browse events.
   - Blog: Read articles.
   - Admin: Dashboard for management.

## Tech Specs
- React + Vite
- Tailwind CSS
- Lucide Icons
